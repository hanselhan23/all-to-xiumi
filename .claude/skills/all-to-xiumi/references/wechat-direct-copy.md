# 公众号直接复制操作与验证

## 实现与选择路径

本路径是“输入 → 公众号兼容的单文件 HTML → 富文本剪贴板 → 公众号正文区”，不使用秀米中转。参考实现以浏览器 Range 选中正文，再执行 `document.execCommand('copy')`。本仓库按钮在真实点击中设置 `text/html` 和 `text/plain`；旧复制接口不可用时尝试 `ClipboardItem`，再失败则保留正文选区供用户手动复制。只确认复制结果，不把它当作平台保存结果。

`all-to-xiumi input.html --wechat-copy --output target.html` 调用 `prepare_wechat_copy`。Markdown/PDF 复用原有模板转换，然后进入同一路径，不额外保留无按钮的重复 HTML。此模式不会调用 `publish_xiumi_draft`，也不需要秀米账号或秀米 CDN。

## 媒体与正文样式

- 正文区域依次识别 `#gzh-content`、`#wechat-content`、`article` 和 `body`，保留其内部嵌套结构。工具栏、成功提示和复制脚本在正文区域外。
- HTML 中的 CSS 规则内联到正文节点，保留字号、字体、颜色、背景、边框、圆角、内边距和自然响应式宽度。正文复制后不依赖页面 `<head>` 或 CSS 类。不能以栅格化整篇正文取代可编辑的文字。
- 相对图片路径以原输入所在目录解析，支持本地图片、HTTP(S) 图片及现有 data URL。图片和 CSS `url()` 背景逐项读入、解码并内嵌；PNG、JPEG、GIF、WebP 原始字节不重编码，记录 SHA-256、固有尺寸、帧数和文件大小。不得用占位图掩盖加载失败。
- 内容依赖媒体查询、伪元素、CSS 变量、脚本、SVG、视频、音频、canvas、iframe 或响应式 `srcset` 时，当前转换器会拒绝无法证明等价的输入。先根据用户授权准备可兼容的布局或公众号原生媒体组件，再验证；不要自行删除艺术字、字体、透明度、图层或动效来换取“通过”。媒体不能仅因为本地浏览器能显示就被标记为公众号可用。
- 浏览器离线单文件能加载图片，不代表公众号后台保存后会保留 data URL。后台可能上传、重编码或清除媒体，也可能改写样式；必须检查保存后重开的内容，不能凭本地预览承诺平台端无损。

## 可重复的复制验证

先安装 `pip install -e ".[wechat]"`。使用本技能 `scripts/verify_wechat_copy.py`，传入产物、原稿和记录位置，例如在仓库中：

```powershell
python .claude/skills/all-to-xiumi/scripts/verify_wechat_copy.py "推送模板/公众号直复制样本.html" --reference "原稿.html" --report "推送模板/验证记录/公众号直复制验证.json" --visual "推送模板/验证记录/公众号直复制对比.png"
```

脚本启动 Chrome，实际点击可见的按钮，核对系统富文本剪贴板，再向独立的原生 `contenteditable` 按 Ctrl+V。目标不加载原稿正文的 CSS，不拦截粘贴，也不用直接设置正文 `innerHTML` 伪造结果。默认在 375px、768px 宽度比较原稿、产物和粘贴结果的正文、图片字节、计算样式与截图。Windows 同时检查 CF_HTML 和 Unicode 文本格式。需要时可传 `--driver-path` 指定本机匹配的 ChromeDriver。

验收应包含正文首、中、尾部及所有照片：检查文字是否遗漏、标题/正文尺寸、文字颜色、对话框轮廓与装饰、照片数量及列数、裁切、背景和页尾。动态媒体检查字节与实际播放；为截图暂停动画后恢复。截图对比时清除光标/选区，不改变文章设计。

## 公众号草稿保存验证

此阶段仅在用户明确要求验证公众号保存时执行。用户只要求检查正文富文本复制时，完成上面的剪贴板往返即可；已登录且后台可编辑不等于需要继续操作后台。浏览器测试使用直接绑定目标页面的控制方式，避免全局键盘输入落到聊天或其他窗口。

在已授权、可编辑的目标稿件操作；先检查并保留未保存的人工内容。点击样本的复制按钮，然后在公众号正文区原生粘贴。等待全部图片处理结束，检查其可加载的公众号地址、数量、顺序、比例以及文字样式。只写入当前任务涉及的区域，不发表推送。

实际点击可见的“保存为草稿”或“保存”，等待明确成功提示，再重新打开同一稿件或其后台预览。比较保存后内容与原稿，特别检查字号、行距、背景、边框、照片排版及动效。需要封面才能保存时，使用用户授权素材并保留其原意；不能擅自替换其他稿件或清除素材库。

记录复制测试和后台保存测试的独立结果。只有两个阶段都通过，才报告“直接复制并保存到公众号草稿验证通过”；若图片或布局被平台改写，列出实际差异并修复/再测，不用“复制成功”掩盖问题。保留一个可直接点击复制的样本、必要素材和验证记录；清理本次临时脚本、测试 HTML 和临时截图，保持验收浏览器打开。
